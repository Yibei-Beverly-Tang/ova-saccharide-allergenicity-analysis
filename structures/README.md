# Structure data

This directory contains the public RCSB PDB entry
[1OVA](https://www.rcsb.org/structure/1OVA), the crystal structure of uncleaved
chicken ovalbumin at 1.95 Å resolution.

- PDB DOI: https://doi.org/10.2210/pdb1OVA/pdb
- Structure publication DOI: https://doi.org/10.1016/0022-2836(91)80185-w
- Downloaded from: https://files.rcsb.org/download/1OVA.pdb and
  https://files.rcsb.org/download/1OVA.cif
- Accessed: 2026-07-31

The mmCIF polymer-sequence scheme is used for residue mapping because PDB
author numbering contains insertion codes and must not be treated as a fixed
offset from the UniProt sequence.
