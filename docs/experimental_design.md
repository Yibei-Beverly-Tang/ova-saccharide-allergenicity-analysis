# Proposed Experimental Design Summary

> This document describes a prospective study structure used to design and
> test the Python workflow. It does not document a completed wet-lab
> experiment. All numerical examples elsewhere in this repository are
> simulated.

## Objective

Provide a prospective framework for comparing representative saccharide
classes during modification of ovalbumin (OVA) and for organizing future
structural and allergenicity-related measurements.

## Proposed Comparison

| Class | Representative |
|---|---|
| Disaccharide | Lactose |
| Oligosaccharide | Mannotriose |
| Polysaccharide | Dextran |

### Branch A: Non-Enzymatic Glycation

Matched control, OVA–lactose, OVA–mannotriose, and OVA–dextran groups under
prospective dry-heating conditions.

### Branch B: TG-Assisted Glycosylation

Matched control plus the three representative saccharide groups as a proposed
first-round screen.

### Branch C: Tyr/CA-Assisted Glycosylation

Matched control plus selected saccharide groups as a proposed confirmation
stage. The simulated dataset carries lactose and dextran into this stage solely
to test the analysis code; this is not an experimental selection result.

## Candidate Measurements

| Level | Candidate measurements | Purpose |
|---|---|---|
| Modification | OPA/free amino groups | Estimate modification extent |
| Structure | SDS-PAGE, particle size, hydrophobicity | Characterize structural remodeling |
| Immunoreactivity | IgE-binding assay | Assess antibody recognition |
| Cellular response | BMDC markers/cytokines | Explore immune-response changes |

Higher apparent modification would not automatically demonstrate lower
allergenicity. Future structural and immunological measurements would need to
be interpreted together using appropriate controls and statistical methods.
